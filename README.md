# capestone_Capstone__IMR_Healthcare_XAI_den
AI/ Healthcare Analytics &amp; Explainable AI Capstone Project. Building interpretable machine learning models to predict and explain healthcare claim denial outcomes using California DMHC IMR data.
This repository contains the Master's Data Science Capstone Project developed at UE – University of Europe for Applied Sciences.
The project aims to build a transparent and explainable AI framework capable of predicting whether healthcare claim denials are upheld or overturned during Independent Medical Reviews (IMR). The framework combines machine learning, explainable AI techniques (SHAP), fairness assessment, and healthcare analytics to improve transparency and trust in healthcare decision support systems.

# Dataset
California Department of Managed Health Care (DMHC) Independent Medical Review (IMR) Determinations Dataset
# Project Goals
Predict IMR outcomes, Identify key factors driving decisions, Generate explainable predictions using SHAP, Evaluate fairness and transparency, Develop a decision-support prototype
